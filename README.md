# MY UNIVERSE, MY HUSBAND, MY FOREVER ❤️
### A Complete Cinematic Birthday Surprise Website for Viren

A premium, romantic, emotional, cinematic, and fully animated birthday surprise website dedicated to **VIREN** on his birthday (**14 December 2026**).

---

## 🎨 Theme & Palette

Strictly designed in **Royal Dusty Blue** with zero black or gold elements:
- **Royal Dusty Blue**: `#526D82`
- **Soft Dusty Blue**: `#91A8B8`
- **Cloud White**: `#F8F7F2`
- **Pearl Grey**: `#DCE3E8`
- **Silver Mist**: `#B7C3CC`
- **Deep Slate Blue**: `#344B60`
- **Champagne Beige**: `#D8C7AD`

Typography:
- **Playfair Display**: Main headings & royal titles
- **Cormorant Garamond**: Romantic letters & emotional vows
- **Inter**: Body content, navigation & controls

---

## ✨ Features & Sections Included

1. **Private Love Invitation Screen**:
   - Welcome screen styled as a luxury private invitation.
   - Animated button: `UNLOCK YOUR LOVE SURPRISE`.
   - VIP QR Pass preview link.

2. **Working QR Code Invitation System**:
   - Dynamically binds to the live hosted website URL (`window.location.href`).
   - Supports camera scanning on iPhone & Android.
   - High-resolution **Download Pass** feature (generates luxury card image).
   - **Print Pass** option formatted with print media styles.
   - Copy website link fallback with toast feedback.

3. **Grand Cinematic Birthday Reveal**:
   - Sentence-by-sentence cinematic text animation:
     - *"Today is not just another day..."*
     - *"Today, the universe gave me the most beautiful gift."*
     - *"Today is the birthday of the person who means everything to me."*
     - *"HAPPY BIRTHDAY, VIREN!"*
   - White & silver confetti showers (`canvas-confetti`).
   - Floating soft-blue hearts and stars.
   - **Interactive Birthday Cake**:
     - Realistic flickering candle flames.
     - Interactive candle blowing (click/tap to blow out candles, realistic smoke puffs, confetti blast).
     - Relight candles button.

4. **Floating Music Player ("Tu Se Hi – Jab We Met")**:
   - Built-in Web Audio API romantic acoustic piano melody engine for "Tu Se Hi" that never fails or gets blocked by CORS.
   - Real-time 12-bar frequency visualizer.
   - Play/pause, mute/unmute, and volume adjustment slider.
   - Minimizable widget that stays persistent as Viren scrolls.
   - Fallback `PLAY OUR SONG ❤️` button if browser blocks initial autoplay.

5. **A Letter From My Heart**:
   - Animated pearl-white envelope with a dusty-blue wax seal (`OPEN MY HEART ❤️`).
   - Unfolds smoothly into a handwritten-style love letter in Cormorant Garamond.
   - Fold envelope back option.

6. **10 Reasons Why I Love You**:
   - 10 interactive pearl-white cards with dusty-blue borders and silver shadows.
   - 3D flip card animations revealing each exact love reason.
   - Progress counter (e.g. `6 / 10 Discovered`) and "Reveal All" helper.

7. **Five Little Surprises for My King**:
   - 5 interactive gift boxes with dusty-blue ribbons & silver tags.
   - Animated untying and lid lifting to reveal Secret Message, Promise, Wish, Confession, and Forever.

8. **Our Beautiful Love Story (Timeline)**:
   - Vertical relationship timeline with illustrated romantic milestones.
   - Custom SVG illustrations (wedding rings, white roses, royal crown).
   - Editable memory notes that persist in `localStorage`.

9. **My Birthday Wishes For You**:
   - "MY WISHES FOR MY KING" with animated typography on pearl-white backdrop with silver glowing accents.

10. **My Forever Promise**:
    - Cinematic dusty-blue section with animated silver infinity symbol and eternal vows.

11. **Final Surprise – One Last Message**:
    - "VIREN, BEFORE YOU LEAVE, THERE IS ONE LAST THING..."
    - Glowing pearl-white heart and reveal of the final emotional letter.
    - Full-screen silver fireworks canvas animation.
    - Grand final screen with replay and QR pass shortcuts.

## 🚀 Getting Started

### Local Development
```bash
npm install
npm run dev
```
Open [http://localhost:5173](http://localhost:5173) in your browser.

### Production Build
```bash
npm run build
npm run preview
```
The output in the `dist` folder can be deployed instantly to Vercel, Netlify, GitHub Pages, or any host.
